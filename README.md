# Afro Carnival 2.0 | Nyali, Mombasa

An interactive Instagram carousel showcasing Afro Carnival 2.0 event in Nyali, Mombasa.

## Features

- 🎠 Smooth carousel transitions
- 🎨 Modern dark theme with vibrant accents
- 📱 Fully responsive design
- ⌨️ Keyboard navigation support
- 🖱️ Mouse and touch-friendly controls
- 🎭 Elegant UI with glass-morphism effects

## How to Use

- **Next/Previous**: Use arrow buttons or keyboard arrows
- **Navigate**: Click dots or thumbnails to jump to a slide
- **Mobile**: Swipe left/right to navigate
